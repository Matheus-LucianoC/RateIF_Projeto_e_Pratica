# Integração Web + Mobile

O RateIF possui front web em Thymeleaf e aplicativo React Native + Expo usando o mesmo backend Spring Boot.

## Módulos

- Autenticação e perfil
- Início
- Turmas
- Conselho de Classe (VdC)

## API mobile

- `/api/mobile/auth/*`
- `/api/mobile/profile`
- `/api/mobile/dashboard`
- `/api/mobile/turmas`
- `/api/mobile/professores`
- `/api/mobile/vdc`

Os dados são persistidos pelo backend no banco configurado pelo RateIF.
